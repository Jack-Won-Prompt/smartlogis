# SmartLogis 사용자 매뉴얼

의료 제품(의료기기/소모품) 간납(간접납품) 물류 시스템 **SmartLogis** 의 업무 사용자 매뉴얼입니다.
역할(소속 유형)에 따라 보이는 메뉴와 처리 업무가 다릅니다. 본인 역할의 매뉴얼을 참고하세요.

## 역할별 매뉴얼

| 역할 | 대상 | 매뉴얼 |
|---|---|---|
| **본사(HQ)** | 삼에스 본사 — 전체 관리·사용분 승인·정산·마스터 | [manual-hq.md](manual-hq.md) |
| **물류창고(WAREHOUSE)** | 삼에스 물류창고 — 입출고·배송·창고 재고 | [manual-warehouse.md](manual-warehouse.md) |
| **거점병원(HOSPITAL)** | 병원 선납창고 — 자기 병원 재고·사용분·반납 | [manual-hospital.md](manual-hospital.md) |
| **공급사(SUPPLIER)** | 공급사 — 자사 제품 재고·납품·매입 정산 | [manual-supplier.md](manual-supplier.md) |
| **라이프사이언스(LIFE)** | 요청/사용 대행 — 재고 조회·사용분·반납 | [manual-life.md](manual-life.md) |

## 공통 사용법

- **로그인**: 이메일 + 비밀번호. (계정은 본사에서 발급/승인)
- **화면 구성**: ① 검색 필터 → ② 리스트(정렬/페이징 10·30·50·100) → ③ 각 리스트 우상단 **[엑셀 다운로드]**(현재 필터 전체 데이터).
- **문서 상세**: 입고·출고·사용분·반납 등 문서 리스트에서 **행을 더블클릭**하면 화면 상단에 **[상세] 탭**이 열립니다. 탭 안에서 **기본정보 / 품목**을 확인하고 승인·확정·피킹·배송 등 처리를 합니다. 여러 문서를 동시에 탭으로 열 수 있고 ✕ 로 닫습니다.
- **바코드 스캔**: 입고 검수·사용분 등록에서 GS1 바코드를 스캔하면 제품·Lot·유통기한이 자동 입력됩니다.
- **알림**: 상단 종 아이콘 및 [알림 센터]에서 안전재고 미달·유통기한 임박·사용분 상태 등을 확인합니다.

> 이 매뉴얼의 모든 화면 이미지는 [images/](images/) 폴더에 있으며, 각 항목에 파일명을 명시했습니다.
